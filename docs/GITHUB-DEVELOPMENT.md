# نسخة التطوير المستقلة من GitHub

هذه الوثيقة تشرح تشغيل نسخة تطوير منفصلة من مستودع Tajeer. لا تستخدم قاعدة الإنتاج، ولا تنفذ migrations تلقائياً.

## Clone وInstall

```bash
git clone https://github.com/musaad002-sketch/tajeerk-rental-dashboard.git
cd tajeerk-rental-dashboard
pnpm install --frozen-lockfile
```

## Build وCheck

```bash
pnpm check
pnpm build
```

يحتاج `pnpm check` إلى TypeScript فقط، ويحتاج `pnpm build` إلى بناء الواجهة والخادم. لا يحتاج أي منهما إلى تشغيل migrations.

## Test بدون قاعدة الإنتاج

للتأكد من سلامة الاختبارات الوحدوية في بيئة لا تحتوي اتصالاً بقاعدة الإنتاج، شغّل:

```bash
env -u DATABASE_URL pnpm test
```

اختبارات التكامل التي تعتمد على `DATABASE_URL` يتم تخطيها تلقائياً عند عدم وجود المتغير. لا تضع عنوان قاعدة الإنتاج في نسخة التطوير.

## إعداد قاعدة محلية اختيارية

إذا احتاج المطور اختبار تكامل محلياً، يجب إنشاء قاعدة MySQL أو MariaDB منفصلة، ثم تعيين `DATABASE_URL` محلياً فقط. لا تشغّل `pnpm db:push` على قاعدة الإنتاج. أي تطبيق migrations على قاعدة محلية يجب أن يكون قراراً منفصلاً بعد مراجعة ملفات Drizzle.

## الأسرار والمصادقة

لا تحفظ ملفات البيئة أو كلمات المرور في GitHub. يجب إدخال المتغيرات محلياً أو عبر مدير أسرار بيئة التطوير. لا تغيّر Authentication في هذه النسخة؛ استخدم إعدادات التشغيل المحلية الموثقة عند الحاجة، ولا تعِد استخدام أسرار الإنتاج.

## نقطة الانطلاق

المستودع يطابق نسخة المشروع الحالية التي اجتازت `pnpm check` و`pnpm build` و`pnpm test` قبل التصدير. قاعدة البيانات والإنتاج منفصلان عن المستودع.
